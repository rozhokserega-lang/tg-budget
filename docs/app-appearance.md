# Фон приложения

Профиль → Оформление и язык → Фон приложения. Выбор применяется сразу ко всем разделам.

- Семь CSS-оформлений: стандартный, тёмный, светлый, градиент, волны, геометрия и мелкая текстура.
- JPG/PNG/WebP до 10 МиБ: декодирование, уменьшение длинной стороны до 1920 px, WebP quality 0.82 (canvas fallback формата поддерживается браузером).
- Cover / по ширине / по высоте, X/Y 0–100%, затемнение 0–80%, blur 0–20 px, непрозрачность карточек 60–100%.
- Фото: IndexedDB `budget-assets` v1 → `images` → `app-background`. Существующая обложка баланса `home-cover` независима.
- Настройки: JSON в localStorage `budget.appearance`. Изображение и Base64 туда не записываются; сетевых запросов для фонов нет.
- Единый fixed-слой вне #app, без background-attachment, pointer events и фоновой анимации. Высота 100lvh не зависит от открытия клавиатуры. Blur выполняется только на фоновом слое. Формы/диалоги остаются непрозрачными; существующая геометрия dock сохранена.
- Настройки восстанавливаются скриптом в head. Загрузка фото ожидается перед скрытием loader, максимум 1800 мс, затем стандартный фон. Повреждённые/отсутствующие изображения дают такой же fallback. Object URL освобождаются при замене/сбросе и после декодирования.
- Safe areas: существующие --safe-top/--safe-bottom учитывают env и Telegram safeAreaInset/contentSafeAreaInset, обновляются при событиях SDK.
- Стандартное оформление восстанавливается одной кнопкой; фото приложения удаляется, обложка баланса и выбор темы/языка сохраняются.

## Проверки

`node --test tests/*.test.cjs`, `node --check src/appearance.js`, `node --check src/app.js`, `node --check src/telegram.js`, `node scripts/version-assets.mjs`, `git diff --check`.

Новые сценарии покрывают границы настроек, мгновенное применение CSS, запись сжатого Blob/восстановление, сброс без удаления обложки баланса, MIME/размер/повреждение/квоту и освобождение URL.

Автоматическая визуальная проверка Playwright/Chromium запущена, но браузер блокируется средой: `socket() failed: Operation not permitted`. Не подтверждены реальные Android/iOS WebView, поведение клавиатуры, scroll/swipe/pull-to-refresh и контраст на всех экранах. Перед слиянием проверить их вручную в Telegram на 320/390/430 px и Desktop, включая светлую/тёмную тему, открытые формы, календарь и dock. Светлый фон и палитра интерфейса выбираются независимо; для светлого оформления доступна существующая светлая тема ниже на странице.

Файлы хранятся только в текущем браузере/устройстве: очистка данных удалит фото; синхронизации между устройствами нет. Декодирование исходных очень больших по разрешению фото может требовать памяти WebView. Текстура имитируется CSS, без bitmap-шума. Исходный утверждённый макет не приложен к задаче; экран использует существующую палитру/карточки приложения.
