# Бюджет пары — Telegram Mini App

Клиент к Edge Function `api` (папка `../files`). Без сборки и зависимостей: статические файлы, тема — из `Telegram.WebApp.themeParams`.

## Что умеет

- **Онбординг** — создать семью или подключиться по коду приглашения, после создания код можно скопировать.
- **Сводка месяца** — доходы, расходы, остаток; план/факт по категориям с прогресс-барами; расчёт между партнёрами («вернуть» / «должен»), режим деления показывается внизу блока.
- **Траты** — список по дням за выбранный месяц (доходы зелёные, расходы красные, бейдж «общий», автор записи). Переход по месяцам — стрелками в шапке.
- **Добавление** — расход/доход, сумма (понимает и `1 234,50`), сетка категорий, заметка, флаг «общий расход», дата.
- **Удаление** — свайп строки влево (или кнопка «···») → «Удалить» → подтверждение.
- **Планы** — цели (пополнить, прогресс, «осталось N · по M/мес»), долги (быстрые выплаты 1 000 / 5 000 / весь остаток), желания (приоритет, «Купить»).
- **Промокод** — в настройках: продлевает доступ; экран блокировки после истечения предлагает ввести код. В боте: `/промо КОД`.
- **Оплата звёздами** — тарифы «1 месяц / 3 месяца / Год» за Telegram Stars; счёт создаёт функция `api`, оплату ведёт Telegram, доступ продлевает бот по `successful_payment`.
- **Документы и данные** — ссылки на оферту и политику (`legal/terms.html`, `legal/privacy.html`), удаление аккаунта.
- **Настройки** — семья, участник, режим деления, остаток пробного периода, код приглашения, обновление.

Системная кнопка «Назад» в форме добавления возвращает на сводку; в остальных местах скрыта. Всё, что делает API, защищено `initData` — приложение само не обращается к Supabase.

## Настройка

1. Адрес функции задан в `index.html` (`window.APP_API_URL`):
   ```
   https://iqbbjkjzxtdqtuwhiadj.supabase.co/functions/v1/api
   ```
   Из браузера его можно переопределить параметром `?api=https://...`.
2. В Supabase secrets должны быть заданы `BOT_TOKEN`, `WEBHOOK_SECRET`, `APP_URL` (см. `../files/SETUP.md`), функции `api` и `bot` — задеплоены.
3. Разместите папку `miniapp/` на любом статическом хостинге с HTTPS (GitHub Pages, Netlify, Cloudflare Pages).
4. В @BotFather → Bot Settings → Menu Button (или в кнопке `web_app` из `bot/index.ts`) укажите адрес Mini App.
5. `APP_ORIGIN` в Supabase secrets должен совпадать с доменом Mini App — от него зависит CORS (`Access-Control-Allow-Origin`).

## Локальная проверка

```bash
cd teletreker/miniapp
python3 -m http.server 8765
# открыть http://localhost:8765/index.html
```

Вне Telegram приложение работает в **демо-режиме** (`src/demo.js`): одинаковый с API контракт, вымышленные данные в памяти страницы. Чтобы обратиться к настоящему бэкенду из браузера, откройте `?api=<адрес функции>` (внутри Telegram `initData` берётся из SDK автоматически).

| Параметр | Что делает |
| --- | --- |
| (без параметров) | демо-семья из двух человек с тратами |
| `?onboarding` | демо без семьи — для проверки создания и вступления |
| `?expired` | истёкший пробный период: баннер, добавление блокируется |

Иконка (`icons/icon.svg`) и `manifest.webmanifest` — для «Добавить на главный экран» и favicon.

## Промокоды

Код хранится в `promo_codes` (миграция `004_promo.sql`), каждое хозяйство активирует его один раз.
Сейчас заведён `FRIENDS2026` — 365 дней. Добавить новый код:

```sql
insert into promo_codes (code, days, note) values ('WINTER2026', 90, 'зимняя акция')
on conflict (code) do nothing;
```

Продление считается от конца текущего доступа (`plan_until`), а не от «сейчас» — стопка кодов складывается.

## Оплата Telegram Stars

Тарифы — таблица `plans` (миграция `005_payments.sql`): `month` 150 ⭐, `quarter` 400 ⭐, `year` 1200 ⭐.
Поток: `create_invoice` → `createInvoiceLink` (`currency: XTR`) → `WebApp.openInvoice` →
`pre_checkout_query` → `answerPreCheckoutQuery` → `successful_payment` → `grant_payment`.

`payments.payload` уникален и `grant_payment` идемпотентна: повторная доставка платежа не продлевает доступ дважды.
Цены меняются в `plans` (например `update plans set stars = 200 where code = 'month'`), без деплоя.

Для проверки до релиза используйте тестовое окружение Telegram (`/test`-боты), там звёзды не списываются по-настоящему.
